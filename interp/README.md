# Пояснения к Python-ноутбуку

Пояснения по интерпретации нейросети и использованию Python-ноутбука interp.ipynb даны в файле [../docs/interp.pdf](../docs/interp.pdf) (docs в корне репозитория).

# Инструкция по запуску Python-ноутбука на Ubuntu

Проверено на Ubuntu версии 22.04.5.

## Установка программного обеспечения в систему

```
sudo apt update && sudo apt upgrade -y
sudo apt install python3 python3-venv python3-pip -y
```

## Настройка виртуального окружения

```
python3 -m venv jupyter_env
```

## Активация виртуального программного окружения

```
source jupyter_env/bin/activate
```

## Установка необходимого программного обеспечения в виртуальное окружение 

```
pip install -r requirements.txt
```

## Запуск сервиса для работы с ноутбуком

```
jupyter notebook interp.ipynb
```

Как правило, в результате запускается автоматически браузер, и ноутбук становится доступным для работы в открытом окне бразуера.

Если этого не произошло, обратите внимание на то, что команда распечатывает в терминале ссылку вида:

```
http://localhost:8888/tree?token=<строка токена>
```
Её следует открыть в браузере и далее выбрать в браузере файл interp.ipynb.

## Закрытие сервиса

Для закрытия сервиса нажмите комбинацию ctrl+c в терминале, где был запущен сервис.

## Деактивация и удаление виртуальной среды

Для деактивации виртуальной среды выполните команду 

```
deactivate
```

Если виртуальная среда больше не требуется, удалите каталог с ее настройками:

```
rm -Rf jupyter_env
```
